Each note cited from a top-level paragraph is moved to just after that paragraph, as a block with the footnote's own id (so the reference still links to it); CSS sets it in the margin on wide screens and under the paragraph on phones. A note cited only from inside a list, quotation, table or heading stays in a short "Notes" list at the end, where the reference also points. A reference to a note that does not exist stops the build. */ -}} {{- $html := . -}} {{- $marker := `

    \s*)?$` "" $note -}} {{- $note = replaceRE `(?s) ]*>.*?` "" $note -}} {{- $order = $order | append $id -}} {{- $notes = merge $notes (dict $id $note) -}} {{- end -}} {{- /* Walk the paragraphs.
